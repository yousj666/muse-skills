# Muse Skills

Personal collection of Muse AI skills.

## Skills

- **mail-relay-monitor** — Check if mail relay and mail server ports are reachable
- **code-compressor** — Compress and minify code (JS/Python), remove dead code
- **server-health** — Check health of Beijing and US servers
- **concise** — Brief, direct responses with zero fluff

## Usage

Copy a skill directory to `~/workspace/skills/` and reference it in conversation.
